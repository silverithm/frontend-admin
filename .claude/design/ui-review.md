작성 2026-09-11 · 운영(carev.kr) 실화면 캡처 기준
적용 원칙: interfaces better-layout / better-ui / better-writing / better-accessibility / better-typography / better-colors

## 검토 범위

실제로 열어본 화면: 대시보드, 공지사항, 월간일정, 전자결재, 근무조정, 회원관리, 편의기능(배차관리), 채팅 레일.
**아직 안 본 화면**: 고충·건의함, 자료실, 연간일정, 전자결재 상세/양식, AI 글쓰기, 회의록, `/employee` 전체.
프로젝트 규약 문서: `CLAUDE.md`(Astryx 규칙), `DESIGN.md`, `.claude/astryx-migration-guide.md` — 모두 확인함.

> 작업 중 맥 디스크가 가득 차(잔여 117MB) 소스 라인 확인이 중단됨. 아래 위치 중 **파일:라인이 적힌 것만 소스로 확정**했고, 나머지는 화면 캡처 근거다(`화면 근거`로 표시).

## HIGH — 먼저 고칠 것

### 1. 한 줄에 컨트롤이 9~10개

| 항목 | 내용 |
|---|---|
| 위치 | `src/components/VacationCalendar.tsx:804·829` 근처 툴바 / 월간일정 툴바(화면 근거) |
| 지금 | 근무조정: `월 선택` `‹` `📅` `›` `↻` `휴무 제한 설정` `중요 행사` `엑셀 내보내기` `직원 휴무 추가` `펼치기` = 10개<br>월간일정: `2026년 9월` `‹` `›` `오늘` `진행률` `색상점` `일정+휴무/일정/휴무` `담당 업무` `펼치기` `일정 추가` = 10개 |
| 고칠 방향 | 주행동 1개(`직원 휴무 추가` / `일정 추가`)만 남기고, 나머지는 ① 월 이동은 제목 옆으로 붙이고 ② `휴무 제한 설정`·`중요 행사`·`엑셀 내보내기`는 `⋯` 더보기로 접는다 |
| 왜 | 선택지가 늘수록 고르는 비용이 선형이 아니라 급하게 는다. 지금은 매일 쓰는 버튼과 한 달에 한 번 쓰는 버튼이 같은 무게다 |

### 2. 채워진 버튼이 한 화면에 여러 개

| 항목 | 내용 |
|---|---|
| 위치 | 근무조정 — `직원 휴무 추가`(틸 채움) + 필터 `전체`(틸 채움) 동시 노출 (화면 근거) |
| 고칠 방향 | 채움은 **주행동 하나**에만. 필터의 선택 상태는 채움이 아니라 테두리+굵기 또는 옅은 배경으로 |
| 왜 | better-colors: 한 화면에 색 채운 컨트롤이 여럿이면 무엇이 주행동인지 화면이 답하지 못한다 |

### 3. `승인됨` 배지가 한 화면에 100개 가까이 반복

| 항목 | 내용 |
|---|---|
| 위치 | 근무조정 월 캘린더 셀 (화면 근거) |
| 고칠 방향 | 승인은 기본값이므로 배지를 없애고, **`대기`만** 표시한다. 이름 앞 점 하나로 충분 |
| 왜 | 기본값을 라벨링하면 정보가 아니라 벽지가 된다. 정작 찾아야 할 `대기`가 묻힌다 |

### 4. 색이 의미를 잃음

| 항목 | 내용 |
|---|---|
| 위치 | 월간일정 일정 칩(노랑·초록·파랑·보라·빨강), 근무조정 이니셜 아바타(사람마다 다른 색) (화면 근거) |
| 고칠 방향 | 색 하나에 뜻 하나. 일정 칩은 카테고리 색을 쓰되 **범례를 화면에 두거나** 색 수를 3개 이하로 줄인다. 이니셜 아바타의 무지개색은 뜻이 없으므로 단색으로 |
| 왜 | better-colors: 같은 색이 두 뜻을 가지면 색은 정보가 아니라 장식이 된다 |

## MEDIUM

### 5. 탭 줄이 두 겹으로 쌓임

- 전자결재: `내 결재 내역(0) / 양식 다운로드` 아래 `전체(0) / 진행중(0) / 승인됨(0) / 반려됨(0)`
- 편의기능: `배차관리 / AI 글쓰기 / 회의록` 아래 `배차표 / 달력 / 목록 / 출결 관리`
- 전자결재 탭은 화면 폭을 꽉 채워 **탭 하나의 클릭 영역이 500px를 넘는다**
- 고칠 방향: 1단은 좌측 내비로 올리거나(이미 사이드바에 서브메뉴가 있음 — 중복이다), 2단만 남긴다. 탭 폭은 내용에 맞추고 좌측 정렬

### 6. 타입 위계가 평평함

- 위치: 전역 (Astryx `--font-size-*`), 그리고 **내가 만든 시안**(`.claude/design/Main.dc.html`, `WorkSchedule.dc.html`)
- 지금: 11 / 13 / 16 / 19 — 인접 배율이 1.18~1.23으로 모두 1.25 미만
- 고칠 방향: **ratio를 바꾸지 말고 단계를 건너뛴다.** 본문 13이면 페이지 제목은 19가 아니라 27(3단계 위). 쓰는 크기 수를 줄이고 간격을 벌린다
- 왜: 관리자 화면 밀도 때문에 ratio 1.2를 고른 건 의도(`CLAUDE.md`)지만, 인접 단계만 쓰면 위계가 안 생긴다. 디자인 훅도 같은 지적을 했다

### 7. 인사말이 제품의 목소리가 아님

- 위치: `src/lib/dailyGreeting.ts:20` — "웃는 얼굴로 시작하면 절반은 성공한 하루입니다"
- 고칠 방향: 격언 대신 화면이 아는 사실을 말한다. "오늘 22명 근무, 요양보호사 3명 휴무"
- 왜: better-writing — 아무 서비스나 할 수 있는 문장은 그 제품의 문장이 아니다

### 8. 사이드바 `NEW` 배지 상시 노출

- 위치: `커뮤니티`, `고충·건의함` (화면 근거)
- 고칠 방향: 최초 노출 후 N일 또는 첫 방문 시 사라지게. 항상 새것이면 아무것도 새것이 아니다

### 9. 변하는 숫자에 `tabular-nums` 없음

- 위치: 대시보드 우상단 시계(1초마다 갱신), 각종 건수 배지 (화면 근거 — 소스 미확인)
- 고칠 방향: `font-variant-numeric: tabular-nums`
- 왜: 자릿수 폭이 달라 매 초 흔들린다

### 10. 검색 입력의 라벨이 placeholder뿐

- 위치: 공지사항 `제목, 내용 검색`, 회원관리 `이름 또는 이메일로 검색...`, 근무조정 `직원 이름 검색` (화면 근거)
- 고칠 방향: Astryx `TextInput`의 `isLabelHidden`으로 시각적으로만 숨기고 접근성 라벨은 남긴다
- 왜: placeholder는 입력 시 사라진다. 라벨이 아니다

## LOW

### 11. 빈 상태가 넓은 카드를 비워둠

- 위치: 대시보드 `전자결재 — 대기 중인 결재가 없습니다` (3분할 중 한 칸 전체가 빈 상태)
- 고칠 방향: 내용량이 다른 것에 같은 틀을 주지 않는다. 0건이면 한 줄로 접는다

### 12. 대시보드 3분할 카드의 높이가 내용과 무관하게 동일

- 위치: `공지사항 / 전자결재 / 요양 소식` (화면 근거)
- 고칠 방향: 외부 뉴스(요양 소식)는 우선순위가 가장 낮은데 같은 자리를 차지한다. 폭·순서를 내용 중요도에 맞춘다
