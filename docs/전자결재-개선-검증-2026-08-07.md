## 1. 요청 사항과 구현 요약

| # | 요청 | 구현 결과 |
|---|------|-----------|
| 1 | 인쇄하면 공문 중간 회색선이 안 보임 | 인쇄 시 배경색 강제 출력(`print-color-adjust: exact`)으로 회색 가로줄·라벨 셀 배경이 인쇄물에 나옴 |
| 2 | 하단 발신부가 위로 딸려 올라옴 → 밑에 고정 | 인쇄 페이지를 세로 flex + 최소 높이(266mm)로 두고 발신부에 `margin-top: auto` — 내용이 짧아도 용지 맨 아래 고정 |
| 3 | 기본 공문 양식을 미리 세팅 (가입 즉시 사용) | 표준 양식 9종을 온라인 폼으로 내장. 양식이 0개인 기관은 자동 등록, 언제든 `기본 양식 불러오기`로 재등록(이름 중복은 건너뜀) |
| 4 | 기안 대분류 선택·수정 + 양식을 분류에 넣기 | 양식마다 `대분류` 지정(기본 4종 + 직접 입력). 대분류 이름 일괄 변경 기능 제공 |
| 5 | 결재내역에서 종류별로 골라 보기 | 관리자 결재관리 · 직원 내 결재내역 · 양식 다운로드 3곳에 기안 종류 필터 추가 |

## 4. 특이사항 · 주의점

### 1) 시딩 양식에 기본 결재선이 없으면 기안이 막힌다 — 검증 중 발견해 수정
처음 시딩한 양식에는 결재선이 없어, 기안 제출 시
`"이 양식에는 결재선이 지정되어 있지 않습니다"` 로 막혔다.
"가입하면 바로 사용"이라는 목적과 어긋나므로, **시딩할 때 기관 관리자를 기본 결재자로 넣도록** 수정했다
(`ApprovalTemplateManager.seedDefaultTemplates`). 관리자가 나중에 양식별로 바꿀 수 있다.

### 2) 인쇄 시 배경 그래픽 옵션
회색 가로줄·라벨 배경이 사라지던 원인은 브라우저 인쇄 대화상자가 **기본적으로 배경 그래픽을 빼고** 출력하기 때문이다.
`print-color-adjust: exact`로 강제 출력하도록 해서, 사용자가 옵션을 만지지 않아도 나온다.

### 3) 여러 장 문서의 발신부 위치
1장짜리 문서는 발신부가 용지 맨 아래 고정된다. 2장 이상이면 마지막 장의 **내용 바로 뒤**에 온다
(HTML 인쇄에서 마지막 페이지 하단 고정은 표준적으로 지원되지 않음). 대부분의 공문이 1장이라 실사용엔 문제없다.

### 4) 자동 시딩 조건
자동 시딩은 **양식이 하나도 없는 기관**에서만, 세션당 1회 동작한다.
목록 조회가 실패했을 때는 '양식 0개'로 오인해 중복 생성하지 않도록 막아두었다.

### 5) 체험 계정 기본 데이터
체험(데모) 기관에는 예시 양식 2종(휴가 신청서·비품 구매 신청서)이 이미 들어 있어 자동 시딩이 걸리지 않는다.
기본 양식이 필요하면 `기본 양식 불러오기`를 누르면 된다.
